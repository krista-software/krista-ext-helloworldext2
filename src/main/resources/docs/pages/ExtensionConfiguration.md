# Configuration

The extension is configured through the **Setup** tab in Krista. HelloWorldExt2 does not call any
external system, so there is nothing to configure — it declares no connection fields.

## Setup tab fields

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| *(none)* | — | — | This extension has no connection fields. |

## Required vs optional

Not applicable — there are no fields to validate or save.

## Notes

- Install the extension and go straight to [Supported Requests](pages/supported-requests.md); there is
  no setup step beyond that.
