# Authentication

HelloWorldExt2 requires **no authentication**. It does not call any external system, so there are no
credentials to obtain and no secured fields on the Setup tab.

## Obtaining credentials

Not applicable — this extension has nothing to authenticate against.

## Required scopes / permissions

Not applicable — no external API is called, so no scopes or permissions are required.

## Verifying

Run **Test Connection** in the Setup area. It always succeeds, confirming the extension is loaded;
there is no external connectivity to check.
