# Overview

HelloWorldExt2 is a minimal, self-contained demonstration extension. It does not connect to any
external system — use it to return a fixed "Hello World" greeting directly from a Krista workflow or
agent, as a baseline example of a working extension.

## Use cases

- **Say hello** — return the fixed text "Hello World" with no inputs.

## What you can do

The extension exposes 3 requests across 2 areas — see [Supported Requests](pages/supported-requests.md)
for the full list, or the sidebar for each request's detailed page.

## Before you start

1. No credentials are required — see [Authentication](pages/Authentication.md).
2. No Setup-tab fields need to be configured — see [Configuration](pages/ExtensionConfiguration.md).
3. Run **Test Connection** (Setup area) to confirm the extension is loaded correctly.
